# AI-Powered Customer Service Chatbot

This workspace contains the specification and foundation scaffolding for an AI-powered customer service chatbot for an e-commerce platform.

## Repository Layout

- `backend/` - Spring Boot service foundation
- `frontend/` - Angular application foundation
- `infrastructure/` - Compose, container, and deployment assets
- `specs/` - design, requirements, database, and task list documents

## Foundation Goals

- Keep backend, frontend, and infrastructure concerns separated
- Use versioned APIs under `/api/v1`
- Standardize formatting and configuration defaults
- Prepare the workspace for incremental implementation
